## Important Design Constraints

- vBook may learn from vtext but must not depend on vtext packages or vendor vtext code.
- `manual-json` is a bridge for manual labels or external visual analysis output, not a vtext dependency.
- `build` should remain runnable without external services by default.
- `manifest` should remain an explicit, lower-level command.
- Generated `outputs/` smoke-test files should not be committed.

# vBook需求意向

# 视频 PPT / 案例截图自动提取 \+ 关联知识点完整技术方案

你现有链路：视频→音频转文字→LLM 结构化笔记，缺失**画面视觉信息（PPT、案例图表）**，核心目标：把视频里的 PPT、实战案例图自动截取、OCR 识别、绑定对应文字知识点，形成图文一体笔记。
整套方案分 4 层：视频帧抽取筛选→图像 OCR 理解→图文对齐融合→知识库输出，全流程可代码自动化。

## 一、第一步：自动抽取视频里包含 PPT / 案例图的关键帧（过滤无效画面）

### 1\. 基础工具

- 视频处理底层：OpenCV、FFmpeg（跨平台，Windows/Linux/macOS 通用）

- 核心逻辑：不逐帧全截（浪费算力），**定时抽帧 \+ 画面相似度去重**，只保留画面变化大、大概率是 PPT 切换的帧。

### 2\. 实操流程

1. FFmpeg 批量抽帧：按 2\~5 秒抽取一帧，输出临时图片

```bash
# 每3秒截1帧，输出到frame文件夹
ffmpeg -i lecture.mp4 -vf fps=1/3 frames/frame_%06d.jpg
```

2. 帧去重过滤（OpenCV 感知哈希 phash）
计算每张图片哈希值，哈希差值小 = 画面几乎没变（讲师人脸、空白背景），直接删除；差值大 = PPT 翻页、案例图表出现，保留。

3. 二次筛选：文本占比判定
用 OCR 预检测图片文字面积，纯人像画面文字极少直接丢弃；PPT / 图表文字密集，保留为**候选关键帧**。

### 3\. 进阶优化（区分普通画面和实战案例图）

增加图像分类小模型（轻量开源）：

- 模型：MobileNet、CLIP 轻量微调版

- 分类标签：PPT 幻灯片、数据 K 线图、实战交割单、代码案例、空白黑板、人物镜头
自动打标签，只保留「PPT / 实战图表」类画面，大幅减少无效图片。

## 二、第二步：图像内容解析（OCR \+ 图表结构化）

拿到筛选后的 PPT / 案例截图，需要把图片里的文字、数字、图表信息转成可写入笔记的结构化文本。

### 1\. 通用文字 OCR（PPT 文字提取）

推荐方案：PaddleOCR（中文最优，本地离线，无需联网）
输出结果：图片全部文字、文字坐标、分段信息，直接生成 PPT 原文。

### 2\. 实战图表专项解析（股票 K 线、交割单、收益案例）

分两类处理：

1. **表格类（交割单、回测数据表）**
PaddleOCR \+ 表格识别模型，自动还原 Excel 结构化表格，输出 markdown 表格，直接嵌入笔记。

2. **K 线 / 折线走势图**
两种方案按需选择：

- 轻量方案：CLIP 图文描述 Prompt，LLM 看图生成文字总结（如 “20 日均线支撑买入案例，回调 3% 不破支撑位，后市涨幅 12%”）

- 高精度方案：专业图表识别模型（ChartOCR），提取坐标轴、关键点位、涨跌区间数值。

### 3\. 输出统一格式

每张图片生成三元组：
`[帧时间戳、图片文件、图片完整文本/图表描述]`

## 三、第三步：图文时间轴对齐（核心难点：画面和音频文字绑定）

你之前有**音频转文字 \+ 时间戳**（每段文字对应视频几分几秒），图片也有抽取时的视频时间戳，通过时间戳做关联匹配：

1. 数据准备

- 音频文本库：`{时间段: 语音文字、LLM提炼知识点}`

- 图像库：`{时间戳: PPT/案例图、图内解析文本}`

2. 匹配规则

- 图片时间戳前后 10 秒区间内的语音文字，判定为**该 PPT 对应的讲解内容**

- 合并：语音知识点 \+ PPT 原文 \+ 图表案例描述，合并送入 LLM 二次整合

3. LLM 融合 Prompt 示例

```Plain Text
输入：语音讲解知识点、配套PPT全文、K线实战图表描述
任务：
1. 把PPT文字和口述内容去重融合；
2. 提炼本页核心实战案例（入场逻辑、止损点位、收益结果）；
3. 输出结构化段落，标注【配套截图：xxx.jpg】，形成图文笔记。
```

## 四、第四步：完整自动化工程链路（串联你现有流程）

### 完整流水线

视频文件

1. 音频分离 → Whisper 语音转文字（带时间戳）→ LLM 基础知识点文档

2. 视频画面抽帧 \+ 过滤 → 筛选 PPT / 案例图 → PaddleOCR / 图表解析

3. 时间戳对齐匹配图文数据 → LLM 融合生成图文一体化笔记

4. 输出产物：

    - Markdown 结构化笔记（文字知识点 \+ 嵌入图表描述 \+ 图片路径引用）

    - 本地分类存放所有实战案例截图

    - 可检索知识库（文字 \+ 图片向量检索，后续查知识点可调出对应案例图）

## 五、低成本 / 零代码备选方案（不想写大量代码）

### 方案 A：本地开源一体化工具（开箱即用）

1. VideoSubFinder：自动定位视频中画面变化、幻灯片切换位置，一键导出关键帧

2. PaddleOCR 桌面端：批量识别截图文字

3. 本地 LLM（Qwen/Llama3）：复制语音文本 \+ OCR 文本，Prompt 整合图文笔记

### 方案 B：API 云端轻量化方案（快速落地，无需本地算力）

1. 抽帧：FFmpeg 本地处理

2. OCR：阿里云 / 百度 OCR API

3. 图像理解：GPT\-4V、Claude 3 看图模型，直接上传案例图，让模型总结图表实战逻辑

4. 文本整合：现有 LLM 接口拼接图文信息生成笔记

## 六、进阶增值功能（股票课程专属优化）

1. 案例标签自动归类
LLM 识别案例类型：均线战法、MACD 背离、短线打板、波段回测、止损实战，给每条笔记打标签，方便检索。

2. 向量知识库存储
将笔记文本、图片向量存入 Chroma/FAISS，后续提问 “均线实战案例”，自动召回对应 PPT 截图 \+ 完整讲解笔记。

3. 重复案例去重
多节课重复出现的 K 线案例，自动合并，避免笔记冗余。

## 七、部署最小依赖清单（本地离线方案，无外网也能用）

1. 视频处理：FFmpeg \+ OpenCV\-Python

2. 语音转文字：Whisper（本地）

3. 图像识别：PaddleOCR

4. 图文大模型：Qwen\-VL（本地多模态大模型，可直接输入截图 \+ 文本，一站式整合知识点，省去单独 OCR 步骤，最简方案）

> 重点简化方案：直接用 Qwen\-VL 多模态 LLM，输入视频截图 \+ 对应时间段语音文本，模型一次性完成：OCR 读 PPT、解读股票案例、融合口述知识点，大幅减少中间代码开发量。
>

## 最简落地步骤总结

1. 用 FFmpeg 抽取视频关键帧，过滤仅保留 PPT / 案例图；

2. 用多模态 LLM（Qwen\-VL/GPT4V）同时接收截图 \+ 对应时段语音文字；

3. 设计 Prompt 让模型提炼**实战案例细节**（入场条件、数据、结果）；

4. 输出带图片索引的结构化 Markdown 笔记，完成图文一体知识库。

# vBook 总体设计

> vBook 是参考 vtext 架构风格设计的股票/交易课程多模态知识整理系统。

## 总体架构图

```text
+----------------------+
| vbook CLI / client   |
| - 选择课程输入        |
| - 批处理命令          |
| - 输出目录管理        |
+----------+-----------+
           |
           v
+----------------------+
| vbook pipeline       |
| - 音频与转写          |
| - 视频抽帧            |
| - 视觉分析            |
| - 时间轴对齐          |
| - 图文融合与导出      |
+----------+-----------+
           |
           v
+----------------------+
| vbook outputs        |
| - Markdown 笔记       |
| - 图片素材            |
| - manifest / JSON    |
| - 后续知识索引数据    |
+----------------------+
```

## 领域优先级

MVP 优先处理股票课程中的两类高价值画面：

1. PPT/幻灯片：还原课程知识结构、定义、步骤和战法要点。
2. K 线案例图：还原买卖点、支撑压力、均线形态、行情走势和案例结论。

交割单、收益表、复杂表格、代码画面和通用课程图表放入后续阶段。

## 工程方向

vBook 采用混合骨架起步：目录和职责边界学习 vtext 的 `client/server/common` 分层，但第一阶段业务闭环放在本地 CLI + pipeline 中。`vbook_server` 第一版只创建空包占位，不引入 FastAPI、uvicorn、任务队列或 SSE 进度流。

- `vbook_client`：CLI、批处理、用户参数和输出入口。
- `vbook_server`：未来 API、任务队列、worker、健康检查和进度流；MVP 仅为空包占位。
- `vbook_common`：共享类型、配置、序列化和输出格式。
- `vbook_pipeline`：本地流水线编排和阶段执行。

## 处理阶段

1. 注册视频输入和课程元数据。
2. 导入已有带时间戳 transcript；可选通过外部 `vtext` CLI 生成。
3. 从视频中抽取候选帧。
4. 过滤重复帧和低价值画面。
5. 默认使用多模态模型分析保留画面，OCR 作为 fallback 或辅助输入。
6. 按时间戳把视觉记录与转写片段对齐。
7. 融合讲解文本、PPT 文字和视觉描述，生成知识段落。
8. 导出 `note.md`、图片资产和机器可读 `manifest.json`。

## 配置优先级

沿用 vtext 中验证过的配置优先级：

```text
CLI 参数 > 环境变量 > TOML 配置 > 默认值
```

关键配置包括抽帧间隔、相似度阈值、OCR 后端、视觉模型后端、外部 transcript 命令、时间轴匹配窗口、输出目录和模型选择。

## 错误处理

错误应限定在阶段内。视觉分析失败时，转写和抽帧结果仍应保留；最终融合失败时，OCR 和时间轴对齐结果仍应可检查。面向用户的错误信息必须包含失败阶段、输入路径和建议的下一步命令。

## 测试策略

优先测试配置加载、路径规划、数据模型、输出命名和时间轴对齐。涉及媒体处理的测试应使用小型 fixture 或 mock 外部工具输出。
